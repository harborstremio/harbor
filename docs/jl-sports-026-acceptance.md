## Reliability repairs

- Failed HTTP, malformed JSON schedule data, or network refreshes retain the last good scoreboard with its original `savedAt` timestamp. A successfully published empty event list still clears old games.
- Hero/status/ticker/story surfaces distinguish saved snapshots from live games. Cached data and the first reconnect snapshot cannot emit fresh kickoff/score/final notices.
- Sports story session history and alert deduplication are scoped to the JL account and active local profile. A profile change immediately removes an open story and remounts the alert host, clearing its in-flight effects and visible notices.
- No request URL, authorization transport, sports subscription, API key, or provider entitlement was changed.
