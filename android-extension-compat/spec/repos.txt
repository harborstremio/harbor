# .cs3. Both hops are followed. Archives land in samples/corpus, which is gitignored. A line whose
# document is already a JSON array is treated as a plugin list, which is how the codeberg mirror
# below is reached.

# the MegaRepo plugin itself reads at runtime, recloudstream/cs-repos/repos-db.json, which is what

# guessed at. Three of the five named repositories also appear in it.
