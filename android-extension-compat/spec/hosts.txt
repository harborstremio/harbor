# Every host the sample extensions hand to loadExtractor, plus the domains the layer's own
# registry claims that no archive happens to hand over.
#
# host | extensions that reach it | evidence | probe url | page a probe url is minted off
#
# evidence is how the host was established:
#   bytecode  a string constant in the extension's own converted bytecode, on the path that
#             reaches loadExtractor
#   network   a real response from the extension's own site or api, captured 2026-09-24
#   both      established one way and confirmed the other
#   registry  no archive names this host: it is a domain a builtin extractor claims by its own
#             mainUrl, and the row exists so the gate scores that claim. its extensions column is
#             empty because zero is the honest count, and the gate prints it as 0 ext.
#
# a probe url of - means no url could be captured, and the reason is in EXTRACTORS.md. a host
# that signs its addresses will never have a durable one, so it leaves the probe url empty and
# names a page instead, off which the gate resolves a fresh url of that host before measuring it.
# probe urls are episode scoped and expire; a failed live probe is not by itself a failed
# extractor, which is why the registry column and the live column are reported separately.
#
# every probe url below was taken from a live run on 2026-09-24, either off an extension's own
# resolve attempt or off the host's own index, and was confirmed to answer before being written
# here. an id that has since expired shows up as an error page, not as a broken extractor.

# domains answer one api off one record pool, confirmed 2026-09-24 by asking all nine for the
# same code and reading the same record back, so a code from one is a real url on the rest.
