# host | extensions that reach it | evidence | probe url

# evidence is how the host was established:
#   bytecode  a string constant in the extension's own converted bytecode, on the path that
#             reaches loadExtractor
#   network   a real response from the extension's own site or api, captured 2026-09-24
#   both      established one way and confirmed the other
#
# a probe url of - means no url could be captured, and the reason is in EXTRACTORS.md.
# probe urls are episode scoped and expire; a failed live probe is not by itself a failed
# extractor, which is why the registry column and the live column are reported separately.
#
# every probe url below was taken from a live run on 2026-09-24, either off an extension's own
# resolve attempt or off the host's own index, and was confirmed to answer before being written
# here. an id that has since expired shows up as an error page, not as a broken extractor.
